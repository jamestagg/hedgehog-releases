# Hedgehog releases

Signed downloads of [Hedgehog](https://www.hedgehog.is): find the credentials on
a laptop and see what they could reach. Source code is not published; this
repository only carries release files so that downloads come from a well-known
origin.

Install instructions, documentation and support: https://www.hedgehog.is/download

Every release includes a `SHA256SUMS` file. Hedgehog by QKey Co.
